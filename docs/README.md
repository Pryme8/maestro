# Maestro documentation

Maestro shows everything running on your computer, lets you pause, end or block what a task does not need, and gives you one place to watch and direct AI agents. These pages describe what is built today. Where something is planned and not built, the page says so.

## Start here

- [Install and first run](install.md): get Maestro running on Windows, macOS or Linux, and what it asks permission for.
- [Status](status.md): what works on each system, and what has and has not been tested.

## The pages of the window

- [Base](base.md): the machine at a glance, every running program, and four ways to draw them.
- [Controls](controls.md): pause, resume, end, clear the machine for a task, profiles, network blocks, and undo.
- [Network](network.md): who each program is connected to, and which ports are open.
- [Agents](agents.md): AI agents recognised as crew, with usage reports, budgets and quests.
- [Live](live.md): watch an agent session step by step, start one, approve its steps, and choose which account and model it runs on.
- [Timeline](timeline.md): the last day, events, what agents spent, and achievements.
- [Router](router.md): a ledger of your AI accounts and an advisor that proposes the cheapest route for a task.

## Without the window

- [Command line](command-line.md): every flag, in one list.
